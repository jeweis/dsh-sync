# 第一版方案：加密快照与离线恢复

状态：0.1.0 实现范围。目标运行时：DeepSeek Harness 0.2.1-alpha.5。

本文保留 0.1.0 的备份协议与离线恢复设计。0.2.0 已增加设置页，交互、凭据存储和鉴权方式见 [设置页方案](settings-ui.md)；离线确认流程保持不变。

## 用户目标

已有设备选择 profile 备份到自己的 WebDAV；新设备下载、预览并恢复配置，通过 DSH 自身的安装流程重建插件依赖。文件恢复、依赖安装、环境可用性是三个独立结果，界面和输出不得混淆。

## 数据范围与兼容性

允许采集 `profiles/<name>/{package.json,cordis.patch.yml,pnpm-lock.yaml}`；home patch 单独选择。按字节保留 UTF-8 文本，避免破坏 bundle 顺序、注释、YAML 标签或整行 config 覆盖语义。源文件读取两次，观察到变化就拒绝备份；不承诺跨文件事务快照，备份时应避免同时编辑配置或安装插件。

凭据、环境、机器身份、构建批准、版本豁免、会话和缓存不在 allowlist。配置本身仍可能内嵌密钥，所有快照无条件加密。Skills 与个人指令后续通过独立数据分区加入，不递归复制整个 home。

本地插件依赖无法仅凭路径跨设备重建，因此备份保留信息、预览显示阻塞项、恢复拒绝应用。未来增加源码归档和显式路径映射。锁文件可保留已解析版本，但缺失锁文件或浮动源无法保证精确复原。

## 模块和宿主接入

- `snapshot.mjs`：采集 allowlist、schema/版本/哈希验证及恢复警告。
- `crypto.mjs`：认证加密，固定且有界的 KDF 参数。
- `webdav.mjs`：存储适配器 `put/get/list`；核心引擎不依赖具体 WebDAV 类型，便于后续接 S3。
- `restore.mjs`：目标差异、确认 token、离线写入、事务日志与恢复。
- `engine.mjs`：采集→加密→上传→下载认证验证流程。
- `index.mjs`：Harness `tools` 消费方；注册三个可卸载工具，校验 Standard Schema 配置。
- `cli.mjs`：独立离线管理命令，不启动 Harness，不复制或修改上游源码。

Host 只提供备份、列表和预览；直接恢复运行中的 profile 可能使自身插件被卸载，因此第一版要求离线 CLI。设置页 UI、后台调度与无人值守口令存储不在本版范围。

## 快照协议

远端布局：`<configured-base>/snapshots/<UTC-time>_<UUID>.vault`。每次创建独立对象，PUT 带 `If-None-Match: *`；无可变 HEAD 或共享索引，不存在“最后写入覆盖全部设备”的设计。服务器须遵守 WebDAV 条件写入语义。未来协议必须保留版本拒绝机制。

加密外壳携带 format、version、随机 salt、随机 IV、认证 tag 和 ciphertext。scrypt 参数固定 N=32768/r=8/p=1，派生 32 字节密钥，AES-256-GCM 使用协议常量 AAD。参数不接受来自远端的任意成本值。JSON 明文包含快照 ID、时间、声明的 Harness 版本，以及路径、内容和 SHA-256。GCM 提供认证，文件哈希用于验证结构和生成恢复计划。

HTTPS Basic Auth 连接；不跟随重定向，防止认证头转发。请求有总时限、取消信号与响应大小上限。PROPFIND 只列目录下一层，只接受当前 origin/collection 的合法快照名，拒绝 DTD/实体。对象名暴露备份时间和数量；目录枚举不代表内容已认证。

上传后立即重新下载、解密、校验 ID 和完整内容，成功才返回 verified。上传或网络失败可能已经创建对象，调用者应通过列表确认；本版不承诺 exactly-once。无自动远端删除，也不进行跨设备覆盖同步。

## 恢复事务

1. 下载并认证，再校验协议版本、文件数、总量、allowlist、重复路径、UTF-8内容哈希和配置格式。
2. 读取目标，不创建文件。计划包含源 ID、目标 home、声明运行时版本、文件 before/after 哈希和警告。token 是整份计划的 SHA-256，不是授权凭据。
3. 用户停止所有使用目标 home 的 Harness，通过 `--offline` 声明并提交 token。版本不匹配和本地依赖阻止应用；其他警告由预览审阅。
4. 获取本插件恢复锁，重算计划，拒绝目标变化。预读全部旧内容，将加密日志写入 retained rollback 和 active 两处，之后才改配置。
5. 每个文件写入 private 临时文件、fsync、原子 rename。逐文件检查目标未被改变，结束时再次验证内容。
6. 成功删除 active 日志，保留 rollback；普通失败尝试逆序回滚。崩溃后显式 recover，从 active 或指定 rollback 读取 before/after，对后续编辑产生冲突的文件拒绝覆盖。

事务不是跨文件原子提交，也不保证整机断电下的目录 fsync 持久性；设计依赖离线目标和可恢复日志。保留目标上未列入快照的文件，不传播删除。若用户选择现有 home，额外 patch/lockfile 会保留，需自行审阅；新设备优先恢复到新 home。

## 第一版验收

- 加密 WebDAV 上传、列表、认证下载、零写入预览、恢复和保留回滚完整往返。
- 错误口令、密文修改、未来版本、非法路径、重复文件和错误哈希在目标写入前失败。
- 目标编辑导致 token 失效，缺失 profile 明确报错，symlink 拒绝处理。
- 超时、取消、认证拒绝、重定向、XML 实体、响应超限有界失败。
- 中断事务可恢复；后续编辑不被回滚覆盖；另一恢复操作不能夺取活动锁。
- Host 工具共享引擎，密码不进入工具参数和结果；所有测试使用临时数据。

## 后续顺序

先做真实 WebDAV 与 Harness 隔离 profile 验收，再做恢复引导 UI、依赖安装计划和实际加载检查；随后支持 Skills/指令、凭据独立加密分区、S3、定时备份。多设备双向同步需要共同祖先、三方合并、条件更新及删除语义，单独定义协议，不在 v1 快照格式上假装已完成。
