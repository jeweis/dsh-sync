## 最终交互

1. 连接存储：只填写和测试连接，超时、清除密码放在更多设置。
2. 同步到其他设备：开启、选择内容、解锁；首次比较和冲突继续显式确认。API Key 默认关闭，仅加密同步，凭据读写与并发保护不变；可从更多同步设置进入凭据扩展预览及回退。
3. 备份与恢复：摘要、自动备份开关、更多设置、立即备份、恢复备份。恢复过程中收起备份控件，避免同时操作；原样文件恢复保留为向导中的高级选项。
4. 恢复：选备份和口令 → 检查摘要与问题 → 准备并复制终端命令。关闭向导或离开备份页签清空向导口令。生成任务不会替换配置文件。
