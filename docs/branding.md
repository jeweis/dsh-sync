# DSH Sync · 同步与备份

项目名为 **DSH Sync**，中文名称继续使用「同步与备份」。功能涵盖受支持配置、模型、API Key、插件清单的跨设备同步，以及独立历史备份与离线恢复；具体自动生效范围以设置页说明为准。

独立项目目录为 `plugins/dsh-sync`。主 CLI 命令为 `dsh-sync`，旧命令 `dsh-config-vault` 保留为兼容别名。npm 包名为 `@jeweis/dsh-sync`，作用域为 `@jeweis`；未进行发布。

## 保持已有数据兼容

改名不迁移数据，不修改真实 profile。继续使用原有 `config-vault/` 配置与本机状态目录、`DSH_VAULT_*` 环境变量和 WebDAV 密码引用、快照/加密/回滚格式、引用型 Key 内部记录前缀及 CAS 标识、同步空间与远端对象路径。旧快照、保留策略归属和凭据不会因品牌改名而另建一套。

主插件的补丁条目 id、设置页 id、客户端 locale 命名空间、模型工具名及认证 API 路径也保留，避免破坏用户补丁和集成；包入口和新建凭据扩展的模块名随新包名变化。旧模块名不是 npm 层的自动别名；已有安装不能只删旧包，需要明确更新 Harness 的 bundle/module 引用。已接入旧凭据扩展的用户应先按原流程安全回退，再迁移包和重新接入；新工具仍识别旧模块名及原日志配方，不会自动改写 profile。

## 图标与本地化

继续沿用原创蓝色归档盒与回转箭头 `assets/icon.svg`。插件列表通过 `locale/en.json`、`locale/zh.json` 的 `meta.title/description` 和包 `icon` 元数据展示；设置页使用自己的中英文词典。客户端构建从同一 SVG 内嵌图片，不需要额外网络请求。标题旁图片使用空 alt，避免读屏重复报名称。
